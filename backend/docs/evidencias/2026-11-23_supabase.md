## 6. Códigos HTTP de PostgREST (CP-P07, parcial)

| Caso | HTTP | Código |
|---|---|---|
| `Accept-Profile` de un esquema no expuesto | 406 | PGRST106 |
| Parámetro mal formado (`id=xx.1`) | 400 | PGRST100 |
| Valor inválido para el tipo (`id=eq.abc`) | 400 | 22P02 |
| Tabla que no existe | 404 | PGRST205 |
| Función RPC que no existe | 404 | PGRST202 |
| Token inválido | 401 | PGRST301 |
| Sin sesión (llave anon) | 401 | 42501 |
| LECTOR intenta insertar en `comando_actuador` | 403 | 42501 |
| LECTOR intenta `PATCH` a `umbral` | 200 `[]` | 0 filas: RLS filtra, no es error |

No se provocó el 409 (llave duplicada).
